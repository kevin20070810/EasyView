# EasyView 简界：常用网站敬老版与当前网页候选版

这是一个 Manifest V3 Chrome 扩展，有两种工作方式。

**通用网页（默认走分析服务）**：在其他普通 HTTP(S) 网页点击扩展图标，扩展在**当前页面内**读出结构，
交给分析服务理解，再渲染成几张老人看得懂的大按钮卡片。理解由模型完成，服务不可用时自动退回本地规则版。

**专用站点（扩展内置，不联网）**：在中国铁路 12306、中国移动、中国天气网和中国邮政显示专用大字敬老版覆盖层。
当前匹配 `https://*.12306.cn/*`、`https://10086.cn/*`、`https://*.10086.cn/*`、`https://www.weather.com.cn/*`、`https://www.11185.cn/*` 和 `https://11185.cn/*`。

> 通用网页会把你**当前页面的结构**（元素文字、链接地址、表单标签）发到分析服务。
> 不读取已填写的内容，不上传账号密码。专用站点模式完全在本地完成，不连服务端，也不访问 AI 服务。

## 加载扩展

1. 在 Chrome 打开 `chrome://extensions`。
2. 开启右上角“开发者模式”。
3. 点击“加载未打包的扩展程序”。
4. 选择本目录 `easyview-extension/`。
5. 打开支持的 12306、中国移动、中国天气网或中国邮政页面；右下角应出现“敬老版”，也可以点击浏览器工具栏的扩展图标打开。其他普通网页可点击扩展图标生成候选版。修改文件后回到扩展管理页点击刷新，再刷新目标页面。

## 通用网页敬老版（走分析服务）

1. 先启动分析服务：

   ```bash
   cd ai-service
   python app.py --host 127.0.0.1 --port 8787
   ```

   不配 `EASYVIEW_API_KEY` 时服务只跑规则引擎，同样能用。

2. 在任意普通 HTTP(S) 网页点击浏览器工具栏的 EasyView 图标。

3. 扩展会：在当前页面内提取结构 → 发给分析服务 → 渲染出最多 7 张大字卡片。

4. 点击卡片：
   - **同站链接**直接进入对应页面；**跨站入口**在新标签页打开
   - **需要本人信息的页面**（查报告、查医保等）会先弹一句确认，您点「继续」才打开
   - **涉钱、涉提交、涉身份**的入口只把您送到原网页，由您自己在官方页面办理 —— 扩展不代付、不代提交
   - **表单**只帮您滚动定位并聚焦，填写和提交仍然在原网页

服务地址默认 `http://127.0.0.1:8787`，可在 `chrome.storage.local` 的 `easyview.aiEndpoint` 里改。

### 分析服务连不上时会怎样

扩展会显示原因，并给出两个出口：「再试一次」，或「用本地规则版」——
后者退回扩展内置的关键词规则（不联网），仍能生成一份基础的大字入口列表。

### 通用网页模式的数据边界

只读取当前页面的**可见标题、链接地址、表单字段标签和结构**，不读取已填写的内容，不上传账号密码。
有支付、登录、身份证等敏感词的入口不会生成卡片。它不会自动登录、代填、提交、付款或退订。
页面变化后请重新点一次图标；没有可靠入口时会明确告知，原网页始终可用。

## 12306 检查步骤

1. 在 12306 首页确认右下角出现“敬老版”。
2. 点击后检查首页按顺序显示“我要买票、查看我的车票、改签 / 退票、重点旅客预约、拨打铁路客服、常见问题”六张卡片，以及独立的登录入口、“其他服务”和“退出敬老版”。
3. 点击“我要买票”，逐步填写出发地、到达地和日期。乘车人姓名、证件信息应在后续 12306 官方购票页面填写。
4. 确认信息后点击“查询车票”。扩展尝试设置页面原有输入框、验证城市输入框/站码确认，再点击页面原有查询按钮。结果应由 12306 页面呈现。
5. 在 12306 车票查询结果页打开“筛选可预订车次”，切换“仅看可预订车次”和发车时段，再关闭覆盖层查看 12306 的结果列表。
6. 点击“查询中转换乘”，检查按钮进入 12306 官方换乘页面；未登录时应由 12306 自行跳转官方登录页。
7. 检查“查看我的车票”和“重点旅客预约”进入对应的 12306 官方页面；“拨打铁路客服”使用 `tel:12306`；“常见问题”滚动到扩展内的帮助段落。
8. 分别打开登录、改签 / 退票、候补引导页，检查按钮进入真实 12306 登录页、火车票订单页、查询页和候补订单页。
9. 检查老年出行说明没有承诺所有车次统一折扣；适用优惠以 12306 当前车次和订单页为准。
10. 任意步骤点击“退出敬老版”，确认覆盖层关闭且无需刷新页面。
11. 在 12306 其他页面重复检查；无法定位入口时应显示提示，可退出后使用原页面。

## 当前支持

### 品牌与 Logo（所有站点复用）

覆盖层不再写死颜色和图标，统一由 `src/brand.js` 从原站页面读品牌令牌：

- `EasyViewBrand.extract()` 返回 `{ name, logoUrl, logoText, brand, brandDeep, accent, text, muted, surface, line, focus, fontFamily, radius, dark }`，
  颜色取自原站的 CSS 变量、主色块和主题色声明，取不到才回退到内置的中性值。
- `EasyViewBrand.apply(theme, target)` 把令牌写成 `--ev-brand / --ev-accent / --ev-radius / --ev-font` 等 CSS 变量，
  挂在 Shadow DOM 的宿主元素上靠继承生效，样式表里不再出现站点专属的硬编码色值。
- `EasyViewBrand.mountLogo(container, theme)` 挂原站 Logo；图片挂了会换成文字标识，页头已有标题时传 `{ textFallback: false }` 直接收起。
- `EasyViewBrand.logoRepeatsHeading(theme, heading)` 判断 Logo 是不是自带站名（12306、中国移动都是 wordmark），
  是的话标题只留给读屏，页头不会重复显示两遍站名。

选主色时按“加权得分 × 颜色在多少个元素上重复出现”排序，而不是单看累加权重：
品牌色通常铺在页头、导航和多个按钮上，页面里一个孤零零的促销按钮不该盖过它。
浏览器给未访问链接的默认蓝 `#0000ee` 会被直接排除，否则几十个没设色的 `<a>` 会盖住真品牌色。

新增站点时只需要在 `content_scripts` 的 `js` 数组里把 `src/brand.js` 放在覆盖层脚本之前，
然后在覆盖层的 `create()` / `show()` 里调一次 `extract` + `apply` 即可，不必再配一套配色。
实测量到的品牌色：12306 `#0472e7`、中国移动 `#e40077`、中国邮政 `#02782e`。

对应的自动检查是 `tools/dedicated_site_check.py`：

    python tools/dedicated_site_check.py --sites 12306,10086,postal

它会加载扩展、打开真实站点、点开悬浮按钮，核对 `--ev-brand` 是否等于原站主色、Logo 是否真的加载出来、
任务卡片能否点进去，并把截图写到 `tools/shots/`。

单独排查某个站点的取色和 Logo 时用 `tools/brand_probe.py`（加 `--dump-samples` 可看加权采样明细）：

    python tools/brand_probe.py --urls https://www.bilibili.com/,https://www.12306.cn/index/
    python tools/brand_probe.py --dump-samples --urls https://www.12306.cn/index/

## 当前限制

- 12306 页面会更新。实际控件是否接受脚本事件、城市候选如何更新隐藏站码，取决于当前页面实现和登录/页面状态；请按上述步骤在真实页面验证。
- 若 12306 未接受城市或日期，扩展会阻止点击查询并提示改用原页面。没有调用私有接口、自动登录或支付。
- 拨打客服依赖设备上的电话处理程序；桌面电脑可能无法直接拨号。
- “本人车票”和“重点旅客预约”可能要求先在 12306 登录。扩展只引导跳转，不读取车票或身份信息。
- 退票和候补目前提供官方页面引导，扩展不会代替用户选择订单、提交候补、付款或确认退票。
- 可预订车次筛选依赖 12306 查询页当前的 `#avail_ticket` 与 `#cc_start_time` 控件；其他页面会提示先打开车票查询。是否有可购席位以 12306 结果为准。
- 中转换乘页面目前会要求登录；扩展不接管登录或保存身份信息。若站点页面变更，官方入口仍可从 12306 原页面进入。
- 季节性、车次限定的老年票价活动会变化；扩展不计算或保证折扣，实际金额以 12306 为准。
- 当前版本仅面向桌面 Chrome 未打包加载流程。

### 中国移动当前限制

- 中国移动的登录、短信验证、账户余额、套餐余量、业务退订和支付由官网处理。扩展不调用中国移动私有接口，也不显示模拟查询结果。
- 充值同步依赖商城首页当前的 `.con_hfcz` 原生表单及固定金额选项。页面变化或无法确认输入时会显示提示，不会触发交费。
- 营业厅入口是官方省份列表，当前不做地理定位或“最近网点”排序。
- 尚需在真实 Chrome、登录状态和各地市页面上检查完整链路。

## 中国天气网敬老版

在 `www.weather.com.cn` 页面，首页显示今天天气、未来一周天气、天气预警、穿衣与健康、查查别的城市、打电话问天气六张卡片。打开具体城市页时，扩展从中国天气网公开页面读取预报和生活指数；首页没有可靠城市信息时，点击今天、一周或健康卡片会直接引导选城市。不会把示例里的“18°C”当作真实气温。

- 今天天气：优先显示原页面的实况气温；如果没有实况，清楚标注“今日最高”，并展示白天和夜间天气。
- 未来一周：从官方七天预报提取每日天气和高低温；当某天最高温比前一天低至少 5°C 时，提示添衣。卡片滚动到大字七天列表。
- 天气预警：只有当前页面出现可确认属于该城市的预警时才置顶。其他情况不宣称“无预警”，提供[官方预警页面](https://www.weather.com.cn/alarm/)入口。
- 穿衣与健康：读取原页面生活指数和提示，展示感冒、穿衣、运动、花粉过敏和紫外线建议；不生成医疗诊断。
- 查查别的城市：通过原页面城市搜索框查找；能在官方城市列表中精确匹配时进入对应官方城市页，否则显示原搜索框供用户选择。
- 打电话问天气：先显示大字号码 `12121`，再提供 `tel:12121` 拨号入口；是否能拨号及通话费用以本地运营商为准。

### 中国天气网检查步骤

1. 打开[北京今日天气页](https://www.weather.com.cn/weather1d/101010100.shtml)，点击右下角“敬老版”，核对城市名、今天白天/夜间温度及生活指数与原页面一致。
2. 点击“未来一周天气”，检查滚动到七天大字列表，并与[北京七天预报](https://www.weather.com.cn/weather/101010100.shtml)逐项核对。
3. 点击“天气预警”，确认没有可确认的本地预警时不会显示“今天无预警”；可进入官方预警页面。有可确认的本地预警时，卡片应升到首位。
4. 点击“查查别的城市”，输入“上海”，确认进入中国天气网官方上海城市页；其他城市未精确匹配时应回到原页面搜索框选择。
5. 点击“打电话问天气”，检查显示 `12121` 并提供 `tel:12121` 链接；点击“退出敬老版”，确认原页面保持可用。

### 中国天气网当前限制

- 天气网首页和城市页面结构不同；没有明确城市或公开页面读取失败时，不显示虚构温度、生活指数或预警。
- 天气预警只根据当前城市页面可确认的本地预警置顶，扩展不自行调用预警接口或推断全国新闻标题适用于当前城市。
- 12121 声讯服务的可用性和资费可能因地区而异。
- 尚需在真实 Chrome 和不同城市、不同预警状态下检查完整展示。

## 中国邮政敬老版

在 `11185.cn` 首页点击右下角“敬老版”，提供邮件查询、EMS 上门取件、报刊订阅、网点查询、资费查询、邮编查询、防诈骗提醒、客服电话和常见问题入口。

- 邮件查询：先填写邮件编号，再打开中国邮政寄递官方查询页；为保护隐私，单号不会保存或自动传送，用户需在官方页粘贴并查询。

### 中国邮政检查步骤

1. 打开 `https://www.11185.cn/`，确认右下角出现“敬老版”，点击后检查业务卡片和“退出敬老版”。
2. 打开邮件查询卡，填写测试单号，查看资料确认页，再打开中国邮政邮件号查询页。正式查询请在官方页面填入真实单号。
3. 打开上门取件卡，填写测试资料并核对确认页；确认链接打开 EMS 官方预约页面。不要提交未核对的真实寄件资料。
4. 检查报刊商城、全国网点、资费和邮编入口分别打开对应官方页面；确认资费和支付均由官网处理。
5. 检查防诈骗提醒、常见问题和 11185、11183、95580 电话入口；点击“退出敬老版”，确认原页面保持可用。

### 中国邮政当前限制

- 11185 首页为 Vue 单页应用；敬老版入口在页面空闲时注入，不读取或改写官网 SPA 内部数据。
- 表单资料只留在当前覆盖层内存；打开官方页面时不会传输、自动填写或提交。
- 预约取件入口通向 EMS；寄件可用范围和实际预约以 EMS 页面为准。
- 报刊商城和邮政寄递页面由不同官方子域提供，页面加载、登录和订购由对应官网处理。
