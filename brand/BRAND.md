# 暖龄 EasyView · 品牌规范 v1（第一版，待确认）

> 状态：第一版草案。名称与文案待团队确认后定稿；标志图形已可投入使用。
> 生成方式：`brand/src/*.html` 为可编辑源，改完运行 `node brand/render.mjs` 重新出图。

## 1. 名称与口号

| 项 | 内容 |
| --- | --- |
| 中文名 | **暖龄** |
| 英文名 | **EasyView**（保留为技术品牌与仓库名） |
| 宣传语 | 暖龄相伴，上网不难 |
| 产品承诺 | 陪您看清，帮您办妥 |
| 一句话介绍 | 把医院、政务、购票等网站，自动整理成大字、大按钮、只留要办的事 |

命名理由：「暖」是照顾与温度，「龄」尊重地指向年龄而不贴标签；比「易懂 / 简界」更有照护感，比「老人助手」更不标签化。
备选对比见 `out/name-options.png`（伴龄、安伴）。

## 2. 标志

构成 = **一张被守护的卡片 + 一轮暖阳**

- 圆角卡片：整理后的网页（大字标题 + 大按钮）
- 环抱弧线：守护、陪伴
- 顶部暖点：温度与关怀

| 文件 | 用途 |
| --- | --- |
| `logo/mark.svg` | 主标志（深青徽章），默认使用 |
| `logo/mark-light.svg` | 浅色纸面 / 白底页面 |
| `logo/mark-16.svg` | **≤48px 必用**的简化版（浏览器扩展图标、favicon） |
| `logo/lockup-horizontal.svg` | 横版组合：标志 + 暖龄 EasyView + 宣传语 |
| `logo/lockup-stacked.svg` | 竖版组合：海报、启动页 |
| `logo/png/*.png` | 上述各版的位图导出（16 / 32 / 48 / 128 / 512） |

规则：

- 最小尺寸：主标志 ≥ 32px；16px 场景只用 `mark-16.svg`。
- 安全边距：标志四周留白 ≥ 标志宽度的 25%。
- 单色场景（丝印、传真件）用 `out/logo-colour-test.png` 中的反白 / 单色版。

## 3. 色彩

| 角色 | 名称 | 色值 | 用法 |
| --- | --- | --- | --- |
| 主色 | ink 深青 | `#0D5C63` | 标题、标志底、信任感区域 |
| 主色暗端 | ink-deep | `#0A4249` | 渐变暗端、深色底 |
| 行动色 | warm 暖橙 | `#E86A33` | **只给可点击的按钮与"温度"元素** |
| 暖橙浅 | warm-soft | `#F2A65A` | 暖阳点、深色底上的强调字 |
| 背景 | cream 米白 | `#FFF8EC` | 页面 / 海报底 |
| 卡片 | paper 纸白 | `#FFFDF8` | 卡片、面板 |
| 正文 | text | `#1F2933` | 正文 |
| 次要 | muted | `#5B6B76` | 说明文字 |

适老化硬性要求：正文与底色对比 ≥ 7:1；按钮白字与暖橙 ≥ 4.5:1。

## 4. 字体

- 中文：Microsoft YaHei（标题用 700），备选 Noto Sans SC
- 英文 / 数字：Verdana（x 字高大，低视力友好）
- 字号下限：界面正文 ≥ 18px；印刷品正文 ≥ 24px；海报主标题 ≥ 90px

## 5. 语气与文案

- 一律动宾短语、口语化：我要挂号 / 查看报告 / 缴纳水电费 / 看今日新闻
- 称呼用「您」「长辈」；**不出现**「老人」「老年版」「简易版」等标签词
- 句子短，一句一件事；数字用阿拉伯数字

## 6. 禁忌

- 不使用老人头像、拐杖、眼镜、药箱、爱心、医疗十字等刻板符号
- 不把产品说成「老人专用」或医疗辅助工具
- 不拉伸 / 旋转标志，不加描边、投影、渐变替换
- 暖橙不用于大段正文文字

## 7. 文件地图

```
brand/

  src/             可编辑排版源（HTML）
  render.mjs       渲染脚本（node brand/render.mjs，需本机 Edge 或 Chromium）
```
