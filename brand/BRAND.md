## 2. 主标志 v6：「暖阳升卡 · 大字版」（2026-10-02；中心换主题样式、四周调亮、标语暂撤）

构成 = **升起的暖阳 + 一张「大字卡」**

- 卡片中心 = 超大深青「大」字 + 圆形暖橙「去办」按钮：一眼说出产品承诺——**字放大、一步办妥**；不再是抽象横线
- 升起的暖阳（暖橙 `#EE6C2D`、米白笑脸、暖橙光芒）：陪伴与问候，与海报右上角大太阳同一角色
- 卡片（纸白 `#FFFDF8` + 暖黄软投影）：海报同款纸感卡片
- 徽章调亮 = 纸感米白 `#FFF8EC` + 沙色细描边 `#F3E0BA`：与海报纸底一致，整体更亮更亲和

读法：太阳升了，字放大了，点一下圆按钮就办妥。全程不用拐杖 / 眼镜 / 药箱等刻板符号。
标语（字大心不慌，暖龄帮上忙）**暂不进入组合标志**，仅保留在海报 / 幻灯片文案中；需要时一次加回。
存档：v5「暖阳升卡」见本轮提交前版本；v4「双手托卡」见 `logo/v4-archive/`；v2 见 `logo/v2-archive/`。

| 文件 | 用途 |
| --- | --- |
| `logo/mark.svg` | 主标志 v6「暖阳升卡 · 大字版」（米白徽章），默认使用 |
| `logo/mark-light.svg` | **深色底反白版**：去掉徽章底，只留图形（海报页脚、深色界面） |
| `logo/mark-16.svg` | **≤48px 必用**的简化版（浏览器扩展图标、favicon）：留暖阳、卡片、大字块、圆按钮 |
| `logo/v4-archive/` | v4「双手托卡」旧标志存档（mark / mark-light / mark-16） |
| `logo/v2-archive/` | v2「开门见卡」旧标志存档（mark / mark-light / mark-16） |
| `logo/seal.svg` | 「暖印」橙色印章：海报落款、认证感角标，可旋转 ±8° |
| `logo/lockup-horizontal.svg` | 横版组合：标志 + 暖龄 EasyView（标语暂撤） |
| `logo/lockup-stacked.svg` | 竖版组合：标志 + 暖龄 EasyView（标语暂撤） |
| `logo/png/*.png` | 上述各版位图导出（16 / 32 / 48 / 128 / 512，含 seal-128） |

规则：

- 最小尺寸：主标志 ≥ 32px；16px 场景只用 `mark-16.svg`（带字版在小尺寸会糊）。
- 安全边距：标志四周留白 ≥ 标志宽度的 25%。
- 印章只作点缀（海报落款、角标），不单独当主标志用；一张画面最多出现一次。
- 不拉伸 / 旋转主标志（印章除外），不加描边、投影、渐变替换。

## 3. 海报 / 幻灯片体系 v3：纸感亮色（当前主用）

v2 深色版反馈「偏暗、AI 味重」，v3 改为**手写纸感亮色**：

- 底：米白纸面 `#FFFBF2` + 淡青方格 + 细噪点，像一张摊开的手账纸
- 去 AI 味三件套：①所有手绘线条过「抖动」滤镜（feTurbulence 位移），没有完美直线；②楷体手写批注与竖排门联；③标题错位套印（暖橙浅鬼影偏移 6px），像印刷没套准
- 层次元素：和纸胶带标签、手绘太阳 + 半调网点、关键词手绘圈、倾斜浏览器框 + 角上胶带、弹出小卡 + 虚线引线、便签「给长辈的三条规矩」、橙色印章落款、波浪线分隔
- 阴影一律**纯色偏移**（如 12px 14px 0 暖橙 16%），不用发光和模糊渐变
- 主标题：深青 100px 级；关键词「一眼看懂」暖橙 + 手绘椭圆圈
- 共情四件套（v3.1）：①太阳带温和笑脸（亲和力 mascot）；②浏览器内问候条「早上好，今天的事我给您排好了。」（产品语气示范）；③手写语气泡「别急，慢慢看，我等您。」；④主题句「上网的路，以后有人陪您走。」楷体暖橙
- 产品界面语气沿用同一套：问候 + 动宾短语 + 不急不催
- 成品：`out/poster-v3.png`（1080×1620）、`out/slide-v3.png`（1920×1080 路演页）
- 源文件：`src/poster-v3.html`、`src/slide-v3.html`（共用同一套 CSS 语言）
- 深色 v2（`poster-v2.png` / `slide-v2.png`）保留为暗场投影 / 夜间备选

## 4. 色彩

| 角色 | 名称 | 色值 | 用法 |
| --- | --- | --- | --- |
| 主色 | ink 深青 | `#0E6068` | 标题、信任感区域 |
| 徽章 | cream 纸感 | `#FFF8EC` + 描边 `#F3E0BA` | 主标志徽章底（v6 调亮，与海报纸底一致） |
| 行动色 | warm 暖橙 | `#EE6C2D` | **只给可点击的按钮与"温度"元素**、印章 |
| 暖橙浅 | warm-soft | `#F6A64F` | 暖阳、深色底上的强调字、笔触下划线 |
| 背景 | cream 米白 | `#FFF8EC` | 浅色页面 / 卡片内底 |
| 卡片 | paper 纸白 | `#FFFDF8` | 卡片、浏览器框 |
| 正文 | text | `#1F2933` | 浅色底正文 |
| 次要 | muted | `#66757E` | 说明文字 |

适老化硬性要求：正文与底色对比 ≥ 7:1；按钮白字与暖橙 ≥ 4.5:1；深色底正文用米白而非纯白，避免眩光。

## 5. 字体

- 中文：Microsoft YaHei（标题用 700），备选 Noto Sans SC
- 英文 / 数字：Verdana（x 字高大，低视力友好）
- 字号下限：界面正文 ≥ 18px；印刷品正文 ≥ 24px；海报主标题 ≥ 90px

## 6. 语气与文案

- 一律动宾短语、口语化：我要挂号 / 查看报告 / 缴纳水电费 / 看今日新闻
- 称呼用「您」「长辈」；**不出现**「老人」「老年版」「简易版」等标签词
- 句子短，一句一件事；数字用阿拉伯数字

## 7. 禁忌

- 不使用老人头像、拐杖、眼镜、药箱、爱心、医疗十字等刻板符号
- 不把产品说成「老人专用」或医疗辅助工具
- 暖橙不用于大段正文文字
- 竖排口号只用于海报；界面与幻灯片用横排
