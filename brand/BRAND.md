# 暖龄 EasyView · 品牌规范 v2（创意版，待确认）

> 状态：第二版。v1 的「卡片 + 暖阳」升级为「开门见卡」主标志 + 橙色印章 + 深色海报体系；名称与文案仍待团队确认。
> 生成方式：`brand/src/*.html` 为可编辑源，改完运行 `node brand/render.mjs` 重新出图（本机需 Edge）。

## 1. 名称与口号

| 项 | 内容 |
| --- | --- |
| 中文名 | **暖龄** |
| 英文名 | **EasyView**（保留为技术品牌与仓库名） |
| 宣传语 | 暖龄相伴，上网不难 |
| 产品承诺 | 陪您看清，帮您办妥 |
| 主视觉口号 | 网页再乱，也能一眼看懂。 |
| 一句话介绍 | 把医院、政务、购票等网站，自动整理成大字、大按钮、只留要办的事 |

命名理由：「暖」是照顾与温度，「龄」尊重地指向年龄而不贴标签；比「易懂 / 简界」更有照护感，比「老人助手」更不标签化。
备选对比见 `out/name-options.png`（伴龄、安伴）。

## 2. 主标志 v2：「开门见卡」

构成 = **环抱的弧线留一道门 + 门里一张整理好的卡片 + 站在门口的名字**

- 环抱弧线（暖橙）：守护与陪伴；顶部刻意留出的缺口是「一道门」
- 「暖龄」二字站在门口：名字即入口，长辈一眼认出是谁在帮忙
- 门内卡片（米白）：整理后的网页 —— 大字标题、说明行、暖橙大按钮
- 深青渐变徽章：信任、沉稳，也是插件图标的底色

读法：推开门（打开网页），乱糟糟的内容已经被整理成一张能办的卡片。

| 文件 | 用途 |
| --- | --- |
| `logo/mark.svg` | 主标志（深青徽章 + 字），默认使用 |
| `logo/mark-light.svg` | **深色底反白版**：去掉徽章底，只留图形（海报页脚、深色界面） |
| `logo/mark-16.svg` | **≤48px 必用**的简化版（浏览器扩展图标、favicon），无字无弧 |
| `logo/seal.svg` | 「暖印」橙色印章：海报落款、认证感角标，可旋转 ±8° |
| `logo/lockup-horizontal.svg` | 横版组合：标志 + EasyView + 宣传语 |
| `logo/lockup-stacked.svg` | 竖版组合：标志 + EasyView + 宣传语 + 承诺 |
| `logo/png/*.png` | 上述各版位图导出（16 / 32 / 48 / 128 / 512，含 seal-128） |

规则：

- 最小尺寸：主标志 ≥ 32px；16px 场景只用 `mark-16.svg`（带字版在小尺寸会糊）。
- 安全边距：标志四周留白 ≥ 标志宽度的 25%。
- 印章只作点缀（海报落款、角标），不单独当主标志用；一张画面最多出现一次。
- 不拉伸 / 旋转主标志（印章除外），不加描边、投影、渐变替换。

## 3. 海报 / 幻灯片体系 v2（深色）

- 底：深青三段渐变 `#10565E → #0B3E45 → #072B31` + 细噪点，沉稳不刺眼
- 右上「暖阳」出画 + 两圈涟漪环：温度来源，只露一角不抢戏
- 主标题：米白 100px 级，关键词「一眼看懂」换暖橙 + 手写笔触下划线
- 竖排口号（海报专用）：`writing-mode:vertical-rl`，「暖龄相伴 / 上网不难」两列，像门联
- 中部：倾斜 -3° 的浏览器框，内放三张示例卡片；右上角再飞出一张「看今日新闻」小卡（+5°），表示「整理后弹出来」
- 右下：橙色印章旋转 7° 落款
- 底部：场景 chips（看病挂号 / 政务办事 / 出行购票 / 看新闻 / 找兴趣）+ 页脚横版组合
- 成品：`out/poster-v2.png`（1080×1620）、`out/slide-v2.png`（1920×1080 路演页）

## 4. 色彩

| 角色 | 名称 | 色值 | 用法 |
| --- | --- | --- | --- |
| 主色 | ink 深青 | `#0D5C63` | 标题、信任感区域 |
| 徽章渐变 | ink-bright → ink-deep | `#14707A → #0A4249` | 主标志徽章底、深色海报底族 |
| 行动色 | warm 暖橙 | `#E86A33` | **只给可点击的按钮与"温度"元素**、印章 |
| 暖橙浅 | warm-soft | `#F2A65A` | 暖阳、深色底上的强调字、笔触下划线 |
| 背景 | cream 米白 | `#FFF8EC` | 浅色页面 / 卡片内底 |
| 卡片 | paper 纸白 | `#FFFDF8` | 卡片、浏览器框 |
| 正文 | text | `#1F2933` | 浅色底正文 |
| 次要 | muted | `#5B6B76` | 说明文字 |

适老化硬性要求：正文与底色对比 ≥ 7:1；按钮白字与暖橙 ≥ 4.5:1；深色底正文用米白而非纯白，避免眩光。

## 5. 字体

- 中文：Microsoft YaHei（标题用 700），备选 Noto Sans SC
- 英文 / 数字：Verdana（x 字高大，低视力友好）
- 字号下限：界面正文 ≥ 18px；印刷品正文 ≥ 24px；海报主标题 ≥ 90px

## 6. 语气与文案

- 一律动宾短语、口语化：我要挂号 / 查看报告 / 缴纳水电费 / 看今日新闻
- 称呼用「您」「长辈」；**不出现**「老人」「老年版」「简易版」等标签词
- 句子短，一句一件事；数字用阿拉伯数字

## 7. 禁忌

- 不使用老人头像、拐杖、眼镜、药箱、爱心、医疗十字等刻板符号
- 不把产品说成「老人专用」或医疗辅助工具
- 暖橙不用于大段正文文字
- 竖排口号只用于海报；界面与幻灯片用横排
